## Column Glossary
- `symbol`: instrument symbol key in storage/manifests.
- `timeframe`: bar interval key (for example `1m`, `4h`).
- `data_source`: inferred provenance from `source_run_id`.
- `source_run_id`: manifest `last_run_id` value.
- `start_utc` / `end_utc`: manifest availability bounds in normalized UTC ISO format.
- `row_count`: manifest row count for the parquet partition.
- `volume_included`: whether parquet schema includes `volume` column.
- `volume_null_count`: parquet metadata null-count total for `volume` (blank if unavailable).
- `parquet_path`: repository-relative parquet file path.
- `manifest_last_updated_utc`: normalized UTC timestamp from manifest `last_updated`.
